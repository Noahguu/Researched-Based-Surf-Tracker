# Researched-Based-Surf-Tracker

## Overview
This project is a surf tracker which is pretty much a more user specified version of surfline. It will input user preferences for surf, and will use historic data (or user inputted data if availible) in order to predict if a given surf spot will have good surf.

## Project Goal
I am attempting to rebuild an old model of mine with a much more technical, ML and research backed approach, touching on efficiency of specific models, how an ML model processes data, what/how models work best with limited information, and more.

## Data
I am using public data listed in "data_info.md", as well as any personalized surf rankings and other surf rankings I can find

## Personalization
The long term goal is to have a system where a user can input a specific location, as well as their prefered surf conditions, and the model will be able to use the users previously logged data (which can be done after each session at the beach) or historic data from the public data sources, and it will output a ranking out of 10 for how close the surf will match the users desires
